# Budget

Локальный PWA для учёта личных расходов. Без регистрации, backend и телеметрии — все данные лежат в IndexedDB на устройстве.

Стек: React 19, TypeScript (strict), Vite 8, Dexie, date-fns, vite-plugin-pwa. Recharts установлен для экрана статистики (этап 10).

## Изменения ТЗ

**Удаление счёта (заменяет п. 11 «Счета», абзац про удаление).**
При удалении счёта, содержащего операции, запрещено каскадно удалять связанные транзакции. Пользователь обязан выбрать другой существующий счёт, на который будут перенесены все операции. После успешного переноса старый счёт удаляется. Если другого счёта нет, необходимо сначала создать новый счёт.

Реализация:
1. Нет операций — удаление после обычного подтверждения.
2. Есть операции — диалог: число операций, выбор счёта, кнопка «Перенести и удалить счёт».
3. Все `Transaction.accountId` меняются на выбранный счёт; начальный остаток удаляемого счёта прибавляется к выбранному, чтобы общий баланс не изменился.
4. Старый счёт удаляется только после переноса — в той же транзакции Dexie. Любая ошибка откатывает всё.
5. Другого счёта нет — диалог предлагает создать его и после создания возвращает к переносу.
6. Переносить можно только на счёт в той же валюте. Единственный счёт удалить нельзя, даже пустой.

Удаления счёта вместе с операциями в v0.1 нет. Чтобы стереть историю — удалить операции по одной или сбросить все данные (этап 11).

## Проверка на iPhone

Service worker (офлайн-режим) работает только по HTTPS или на localhost.

- Быстро посмотреть интерфейс: `npm run dev -- --host` и открыть `http://<IP-компьютера>:5173` в Safari. Установить на экран «Домой» можно, но без офлайна.
- Полноценно как PWA: задеплоить `dist/` на любой статический хостинг с HTTPS (Cloudflare Pages, Netlify, GitHub Pages) → Safari → «Поделиться» → «На экран Домой».
  - Для Netlify добавьте `public/_redirects` со строкой `/* /index.html 200`, чтобы прямые ссылки на экраны открывались при первом заходе.
  - Для деплоя в подпапку (например, GitHub Pages `/budget/`) укажите `base: '/budget/'` в `vite.config.ts` — роутер и манифест это учитывают.

## Архитектура

```
src/
  app/          App, роутер, layout'ы, навигация (History API)
  pages/        экраны; у Dashboard свой хук useDashboardData
  features/     бизнес-логика по доменам: defaults, repository, calculations
  components/   переиспользуемые UI-компоненты (CSS Modules)
  db/           Dexie: database, schema, migrations, seed
  hooks/        общие хуки (useToday)
  utils/        money, dates, id, plural
  types/        сущности
  styles/       токены темы и глобальные стили
  dev/          моки только для разработки
```

Слои: UI (`pages`, `components`) → логика (`features/*/calculations.ts` — чистые функции) → хранилище (`features/*/repository.ts` → `db/`). Компоненты не обращаются к Dexie напрямую.

### UX-компоненты

- `Dialog` — нативный `<dialog>`: фокус, Esc и top layer делает браузер. На нём построены `Sheet` (нижняя шторка) и подтверждения.
- `useConfirm()` вместо `window.confirm()`, `useToast()` вместо `alert()`.
- `--keyboard-inset` (из `visualViewport`) поднимает кнопку «Добавить», тосты и шторки над клавиатурой iOS. Переменная пишется не чаще раза в кадр и только при фокусе в поле ввода: во время анимации клавиатуры iOS присылает пачку событий с рассогласованными `height` и `offsetTop`, и без этого шторка прыгала по экрану. Поднимаются панели `transform`'ом с коротким переходом — без пересчёта раскладки на каждый кадр.
- Кнопки-переключатели (`ChipGroup`, `SegmentedControl`, выбор иконки категории) отменяют `mousedown`, чтобы фокус остался в поле ввода: иначе тап по «Наличные» закрывал клавиатуру и перестраивал экран.
- `primeKeyboard()` — по тапу на «+» клавиатура открывается сразу, хотя поле суммы появляется чуть позже (iOS разрешает `focus()` только в обработчике жеста).

### Ключевые решения

- **Деньги** — целые копейки (`12550` = 125,50 ₴). Парсинг, форматирование и арифметика только через `Money` из `utils/money.ts`.
- **Даты операций** — строки `yyyy-MM-dd` в локальной зоне: день покупки не «уезжает» при смене часового пояса, а выборка за месяц — простое сравнение строк.
- **Миграции** — `db/migrations.ts`: массив версий, новые только добавляются в конец. `DB_VERSION` вычисляется из последней.
- **ID** — UUID v4 с запасным вариантом для небезопасного контекста (`http://192.168…`), где `crypto.randomUUID` недоступен.
- **Роутер** — ~60 строк на History API вместо react-router (−30 КБ gzip для шести плоских экранов). Если понадобятся вложенные маршруты — меняются только `app/navigation.ts` и `app/router.tsx`.
- **Удаление счёта** — см. «Изменения ТЗ» ниже. Перенос и удаление идут в одной транзакции Dexie; тест `features/accounts/repository.test.ts` роняет её посередине и проверяет откат.
- **Удаление категории** не трогает операции — они показываются как «Без категории».
- **Шрифты** — системные (SF Pro, для сумм SF Pro Rounded). Никаких внешних запросов, в том числе к Google Fonts.

### Liquid Glass

Материал описан один раз в `styles/glass.css` — токены и утилита `.glass`, плюс компонент-обёртка `components/GlassSurface`. Вручную по компонентам стекло не прописывается.

- **Три ступени плотности** (`data-glass="subtle | regular | prominent"`). Чем выше слой, тем плотнее материал — так между ними читается глубина. Мелкие контролы — `subtle`, нижняя навигация — `regular`, шторки и диалоги — `prominent`.
- **Стекло только для плавающих слоёв**: навигация, шторки, переключатель месяца. Карточки с цифрами остаются непрозрачными — сумма важнее эффекта (ТЗ §63).
- **Кнопка «+» сплошная**: полупрозрачная главная кнопка потеряла бы контраст. От стекла у неё только блик и мягкая тень.
- **Blur умеренный** (10/16/22px): на iPhone каждый лишний пиксель размытия — это кадры.
- **Отдельные значения для тем**: одна и та же RGBA в тёмной теме выглядит грязным серым пятном.
- **Два запасных варианта**: `@supports not (backdrop-filter)` и `prefers-reduced-transparency: reduce` заменяют стекло непрозрачной поверхностью. Приложение от размытия не зависит.
- **Фон не плоский**: два очень мягких пятна на весь экран (`.app-backdrop`) — иначе стекло не читается. Фон лежит на `html`, а не на `body`: фон body рисуется как фон обычного блока и спрятал бы слой с отрицательным `z-index`.
- Анимации короткие и мягкие; `prefers-reduced-motion` глушит их глобально.
